# One existing Work publisher: post-legacy roster, ledger, and native phase

Call `python phase.py CONFIG.json CONFIG_SHA /private/fresh-stage/YYYY-MM-DD` immediately after
the existing Work legacy source/control assembly (which remains private after cutover).
This executable has no browser, deploy, promotion, normal publisher, or Git operations.

1. Existing Work supplies the date/season, completed assembly receipt and separately
   retained/checksummed prepared source, native, calibration, exact dated outlook, player,
   signed book, collector, calendar and source-R receipts. See `nov20_verify_config.json`
   (local relative workspace identifiers aren't authorization), and `phase.py:admitted`.
   Same-date legal quote coverage and clocks are derived from all 30 native team tables
   against fresh signed and confirmed-pending ownership and the new role roster; counts are
   derived, never hardcoded for the next observation.
2. For a fresh date supply the explicit additional fields used by `run_ledger`:
   separately pinned d509 rollout tree including the corrected daily scripts from
   `../d509_daily_layout_and_current_assembler.patch`, isolated dated preallocation
   checkout with reviewed early-capture R exporter patch already installed (exact patched
   hash), original accepted ownership receipt, completed-history SHA inventory, BRef raw
   input root, verified outcomes plus outcome audit, and exact R runtime/allocator pins.
   The callback stops before any previous allocation or public export. Work can keep the
   admitted source-R receipt's calendar and demographics in its original live executor
   location; the isolated capture view explicitly rebinds only the same signed-book bytes.
   The exact dated outlook bound in native preparation is used once, not redated or replaced
   with earlier provider forecasts. The phase builds MPG comparables and a single resolved
   game ledger including each true four-season open draft window.
3. First date selects `mode=first-cutover`, with exact private legacy predecessor used by
   this day's legacy control, private separately authorized patch root, patch/path pins,
   and immutable `legacy_prepared` root. It copies payload with only two reviewed source
   hashes changed, leaving original receipt/state untouched. The 3-source native overlay
   makes the exact reviewed downstream minutes integration and endpoint substitutions only.
   Derived cache rebind accepts strictly one source signature difference and keeps every
   calibration parameter unchanged.
4. Every later date uses `mode=continue-shared`, exact last successful shared batch
   manifest + 30 team state files, and the independent SHA-pinned canonical promotion
   receipt `{asof,canonical_verified:true,shared_native_continuation_sha256}`.
   Copy exact shared predecessor bytes with no rebase. Do **not** pass private legacy state
   as the future shared predecessor; comparison of actual Nov20 checkpoints shows the
   role payload differs. If chronological inventory contains other dates after that
   predecessor, stop rather than invoking any unreviewed catch-up method.
5. Consumer outputs are `receipt.json` (find exact batch, scope, game ledger, etc.),
   `shared_native_candidate_receipt.json` (524-priced style eligibility, all endpoint
   versions, exact raw native file hashes), and `shared_native_continuation.json`
   (portable manifest/state digests for the next successful date). Call native serializer
   and released calibrator downstream to generate final player/draft prices, and reuse
   the exact ledger for R/Team/Lineup/Pick; this phase does not certify final dollar or
   preflight/promotion. `verify-retained` is artifact audit only, not proof of a fresh run.

Local actual Nov20 verification passed 526 roster participants, 524 priced identities,
30 teams, 2,008 exact 240-minute regulation team-games, 194 open draft appraisals covering
776 native endpoint cells, and 31 portable state paths. Audited actual retained artifacts
are not re-run. Seal live dated capture (not reconstructed legacy), first fresh phase
invocation and real successful continuation in the sole Work job before enabling cutover.
